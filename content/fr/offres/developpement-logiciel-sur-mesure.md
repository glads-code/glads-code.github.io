Un logiciel métier, une application web ou un produit SaaS doit durer. GLADS conçoit et développe des logiciels maintenables, testés et performants, en C#/.NET, Go, Rust ou C.

## Pour qui ?

- Les entreprises qui ont besoin d'un **logiciel métier** adapté à leurs processus.
- Les **porteurs de projet SaaS** qui veulent un produit fiable dès sa première version.
- Les équipes qui doivent **intégrer plusieurs systèmes** (ERP, CRM, services tiers).

## Ce que nous faisons

- **Applications sur mesure et SaaS** : logiciels métier, applications web, solutions cloud natives.
- **Intégration de systèmes** : API REST, gRPC, architectures événementielles.
- **Optimisation des bases de données** : PostgreSQL, SQL Server, Oracle, jusqu'à 40 % de gain de performance.
- **Reprise de projets existants** : stabilisation, tests, remise à niveau technique.

## Notre démarche

1. **Cadrage** : besoins, priorités et contraintes, découpés en livraisons courtes.
2. **Développement itératif** : une version utilisable à chaque étape, testée automatiquement.
3. **Mise en production** : déploiement automatisé, supervision, documentation.
4. **Maintenance et évolutions** : selon vos besoins.

## Nos engagements

- Code lisible, testé et documenté, que vos équipes peuvent reprendre.
- Des choix technologiques justifiés, sans dépendance inutile.
- Expérience de projets allant jusqu'à 45 000 jours/homme.

## Questions fréquentes

**Quelles technologies utilisez-vous ?** Principalement C#/.NET, Go et Rust, avec PostgreSQL, SQL Server ou Oracle, sur Azure, Kubernetes ou un cloud souverain.

**Pouvez-vous reprendre un logiciel existant ?** Oui, après un audit rapide pour évaluer son état et les risques.

**À qui appartient le code ?** À vous. Le code source et la documentation vous sont livrés.
