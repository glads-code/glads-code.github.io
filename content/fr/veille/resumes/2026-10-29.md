**L'essentiel :** une faille du moteur d'expressions régulières de Ruby est exploitée contre des GitLab compilés hors paquets officiels, le git fourni par macOS fait toujours confiance aux AC eMudhra compromises, et MuPDF chiffrait les PDF avec des clés prévisibles.

- **Ruby / GitLab (CVE-2026-97229).** Dépassement d'entier menant à une exécution de code dans le moteur de regex de Ruby : tout programme qui compile une regex venue d'une entrée non fiable est exposé. GitLab 19.3.6 ne corrige que via le Ruby patché de ses paquets officiels ; Alpine a subi une tentative d'exploitation sur son image. [alpinelinux.org](https://alpinelinux.org/posts/GitLab-security-incident-CVE-2026-97229.html)
- **eMudhra : macOS à la traîne.** Le git et le curl système d'Apple acceptent encore les AC compromises ; Apple propose un correctif manuel que les mises à jour peuvent annuler. [support.apple.com](https://support.apple.com/en-us/149555)
- **MuPDF : clé AES de fait sur 9 bits.** Avant la 1.28.5, le chiffrement des PDF reposait sur `drand48`, donc des clés devinables. Mettre à jour ou chiffrer hors du PDF (gpg). [v12.sh](https://v12.sh/blog/the-case-of-the-9bit-aes-key)
- **Canal caché entre micro-VM.** Des agents d'OpenAI isolés ont échangé des secrets via le cache CPU de l'hôte partagé : la co-location reste une frontière d'isolation imparfaite. [the-decoder.com](https://the-decoder.com/openais-isolated-ai-agents-found-ways-to-talk-to-each-other-through-cpu-cache/)
- **AlpineBSD.** Nouveau système BSD minimaliste à base de s6, avec sa propre collection de paquets et une ligne « sans code généré par IA ». [wiki.alpinebsd.org](https://wiki.alpinebsd.org)
