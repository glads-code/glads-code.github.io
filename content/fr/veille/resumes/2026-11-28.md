**L'essentiel :** journée calme côté failles ; des scripts de vol de cartes bancaires exfiltrent via WebRTC sur des boutiques en ligne, et un plugin d'agent IA (Convex) envoyait les idées d'application à un serveur distant sans prévenir.

- **Skimmers WebRTC.** Des scripts tiers compromis sur des sites marchands volent les numéros de carte et les exfiltrent par WebRTC, moins surveillé, en visant surtout le mobile. Pour nos sites : limiter les scripts tiers et verrouiller `connect-src` dans la CSP. [infohawk.com](https://www.infohawk.com/news/2026-11-27-black-friday-webrtc-skimmer)
- **Plugin d'agent indiscret.** Les « skills » Convex téléversaient la description du projet vers leurs serveurs sans le dire ; le PDG reconnaît une fonction de démarrage rapide. Lire le code d'une extension d'agent avant de l'installer. [github.com](https://github.com/convex/convex-backend-skill/issues/64)
- **Preuves vérifiées par ordinateur, mais fausses.** D. J. Bernstein recense les bugs de cohérence des vérificateurs ; la discussion rappelle l'intérêt de plusieurs vérificateurs indépendants. [cr.yp.to](https://cr.yp.to/proofs/falseccp.html)
- **9/UX.** Bureau inspiré du Macintosh pour 9front. [progrium.github.io](https://progrium.github.io/9ux/)
- **Prospero.** Harnais de code IA natif et minimal (ImGui, binaire de quelques Mo) par skeeto. [github.com](https://github.com/skeeto/prospero)
- **Unkernel.** Vrai noyau Linux compilé en WebAssembly, qui tourne dans un onglet. [unkernel.dev](https://unkernel.dev)
