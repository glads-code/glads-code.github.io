**L'essentiel :** « http2shell » expose les décodeurs Brotli de Node, Python et d'autres à une exécution de code ; OpenBSD 8.0 corrige une faille IPsec exploitable à distance ; une chaîne d'exploits complète contre l'iPhone est démontrée.

- **http2shell : faille mémoire dans Brotli.** Un bug du décodeur Brotli de Google permet une exécution de code via des réponses compressées ; surtout les clients et les serveurs qui décompressent explicitement. Le correctif existait depuis février sans version publiée : mettre à jour les bibliothèques (brotli 1.2.1 pour Python). [news.ycombinator.com](https://news.ycombinator.com/item?id=50216791)
- **OpenBSD 8.0 : premiers errata.** Débordement de tas noyau déclenchable à distance via IPsec AES-GMAC (amd64 avec AES-NI, octeon), correctifs nsd et video(4) ; nouvel outil `dbupdate` pour mettre à jour `cert.pem` et zoneinfo signés. Lancer `syspatch`. [openbsd.org](https://www.openbsd.org/errata80.html)
- **iPhone piraté de bout en bout.** Calif présente une chaîne d'exploits iOS qui passerait par des pièces jointes (PDF, iMessage) : appliquer les mises à jour, le mode Isolement réduit la surface d'attaque. [blog.calif.io](https://blog.calif.io/p/iphone)
- **« Est-ce la nouvelle normale ? »** Billet et débat sur le rythme des failles critiques découvertes par IA et le délai très court avant exploitation massive : raccourcir le cycle de correctifs. [drew.silcock.dev](https://drew.silcock.dev/blog/is-this-the-new-cyber-normal/)
- **UUIDv7, pas si ordonné.** Les horodatages ne garantissent pas l'ordre ; leur intérêt reste la localité d'écriture dans les index, pas le tri. [alexsci.com](https://alexsci.com/blog/uuidv7-is-weird/)
- **uv intègre ty.** Astral réunit gestionnaire de paquets et vérificateur de types Python dans une même chaîne d'outils. [astral.sh](https://astral.sh/blog/uv-ty-integration)
