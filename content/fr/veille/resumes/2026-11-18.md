**L'essentiel :** Java4Shell, une exécution de code à distance dans OpenJDK (décodeur Base64 AVX-512), touche toutes les JVM HotSpot ; pas encore de correctif Temurin, mais un contournement existe.

- **Java4Shell (CVE-2026-114938).** Écriture hors limites du tas dans le décodeur Base64 accéléré AVX-512 de HotSpot (OpenJDK, Oracle, GraalVM), exploitable par le réseau. En attendant les mises à jour, lancer la JVM avec `-XX:-UseBASE64Intrinsics` (x86-64 uniquement). [news.ycombinator.com](https://news.ycombinator.com/item?id=50538240)
- **Quad9 se retire de France.** Le résolveur DNS public quitte le pays face aux ordres de blocage obtenus par les ayants droit ; Cloudflare s'en inquiète. À suivre pour tout choix de résolveur. [news.ycombinator.com](https://news.ycombinator.com/item?id=50538994)
- **Chaîne logicielle Microsoft.** Le paquet PyPI de Microsoft Agent Framework a été compromis, et le dépôt d'ONNX Runtime a disparu de GitHub. Épingler ses dépendances et vérifier leur provenance. [news.ycombinator.com](https://news.ycombinator.com/item?id=50539610)
- **Phrack 73.** Nouveau numéro : évasion de conteneur Docker, portes dérobées dans les modèles d'apprentissage automatique, histoire du phreaking. [news.ycombinator.com](https://news.ycombinator.com/item?id=50535992)
- **Moins de clics depuis Google.** Les réponses IA réduiraient le trafic issu de la recherche d'environ 40 % : à intégrer dans le référencement des sites. [news.ycombinator.com](https://news.ycombinator.com/item?id=50540178)
- **La revue de code devient le goulot.** Une étude de Harvard montre que les agents de code déplacent l'effort vers la relecture. [news.ycombinator.com](https://news.ycombinator.com/item?id=50538303)
