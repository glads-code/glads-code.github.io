**L'essentiel :** la faille Brotli « HTTP2Shell » (CVE-2026-111497) touche bien plus que Node et Python, avec des correctifs encore inégaux ; OpenBSD 7.8 reçoit les mêmes correctifs IPsec et nsd que la 8.0.

- **HTTP2Shell : l'étendue s'élargit.** CVE-2026-111497 (critique) dans le décodeur Brotli touche aussi Git for Windows, Wireshark, ImHex et des applications embarquant Node ; le paquet Debian/Ubuntu `libbrotli1` n'est pas encore corrigé partout. En attendant : mettre à jour dès que possible, voire refuser le `Content-Encoding: br` des requêtes côté proxy. [news.ycombinator.com](https://news.ycombinator.com/item?id=50219177)
- **OpenBSD 7.8 : errata 071 à 075.** Débordement de tas noyau via IPsec AES-GMAC, use-after-free dans video(4), correctifs nsd, isakmpd et ppp(4) : `syspatch` aussi sur la 7.8. [openbsd.org](https://www.openbsd.org/errata78.html)
- **Wine revient dans les ports OpenBSD.** Un port `emulators/wine` est proposé sur la liste ports, avec appel aux tests. [undeadly.org](https://undeadly.org/cgi?action=article;sid=20261022052106)
- **Goose, un langage sans ramasse-miettes ni allocation manuelle.** Par l'auteur de Lobster : des piles allouées statiquement et adossées à la mémoire virtuelle, sûreté mémoire revendiquée. [news.ycombinator.com](https://news.ycombinator.com/item?id=50224100)
- **Roku quitte GitHub pour GitLab.** Les dépôts développeurs déménagent ; le débat porte sur les pannes de GitHub et la dépendance à une seule forge. [news.ycombinator.com](https://news.ycombinator.com/item?id=50222622)
- **« Soyons plus ambitieux » (Dan Luu).** Appel à viser des logiciels plus ambitieux ; la discussion rappelle que maintenabilité et sécurité restent le vrai coût. [news.ycombinator.com](https://news.ycombinator.com/item?id=50225695)
