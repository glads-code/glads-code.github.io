**L'essentiel :** un exploit d'évasion de VM Firecracker (PwnEscape) est détaillé : il visait une configuration sans le *jailer*, ce qui rappelle que l'isolation tient autant au confinement du VMM qu'à l'hyperviseur.

- **Firecracker : évasion de VM en pratique.** PwnEscape, faille divulguée il y a quelques semaines, est exploitée de bout en bout ; le test tournait sans jailer (seccomp, namespaces, privilèges réduits), à garder impérativement en production. [news.ycombinator.com](https://news.ycombinator.com/item?id=50397219)
- **OpenBSD : `top -Q`.** Nouvelle option affichant, par processus, l'usage de chroot(2), pledge(2) et unveil(2) : pratique pour auditer le confinement. [undeadly.org](https://undeadly.org/)
- **libghostty 1.0.** La bibliothèque d'émulation de terminal de Ghostty, à API C stable (handles opaques), sert déjà de base à plusieurs terminaux. [mitchellh.com](https://mitchellh.com/writing/libghostty-1-0)
- **GitHub refond son stockage Git.** Nouvelle architecture pour les très gros dépôts ; elle ne règle pas les pannes récentes (erreurs 500 au push cette semaine). [github.blog](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)
- **Programmer en UEFI sans OS.** Guide pas à pas, sans libc ; astuce : `nm -D --undefined-only` pour repérer les symboles non résolus. [kevinboone.me](https://kevinboone.me/efitest_index.html)
- **Asahi Linux et Linux 7.3.** Nouveau point d'avancement du portage sur Mac Apple Silicon. [asahilinux.org](https://asahilinux.org/2026/11/progress-report-7-3/)
