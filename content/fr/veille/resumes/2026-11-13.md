**L'essentiel :** Une faille de PostgreSQL vieille de 22 ans mène à l'exécution de code sur le serveur depuis un simple compte SQL, et Rust 1.100 apporte les délais de quarantaine des dépendances dans Cargo.

- **PostgreSQL : de la confusion de type au RCE (CVE-2026-6460).** Un compte SQL suffit pour exécuter du code sur le serveur : risque surtout pour les bases mutualisées. Surveiller le correctif dans Debian et les images Docker. [news.ycombinator.com](https://news.ycombinator.com/item?id=50471761)
- **Rust 1.100.** Type never et allocateurs personnalisés stabilisés ; Cargo signale les dépendances inutilisées et peut ignorer les versions publiées trop récemment (`global-min-publish-age`), une parade partielle aux paquets piégés. [news.ycombinator.com](https://news.ycombinator.com/item?id=50472038)
- **Panne géante de Microsoft 365.** Plus de huit heures sans messagerie pour de nombreuses entreprises, avec des serveurs retirés en cascade par leurs contrôles de santé. Rappel du risque de dépendre d'un seul fournisseur. [news.ycombinator.com](https://news.ycombinator.com/item?id=50471731)
- **Jensen Huang quitte Nvidia.** Démission sur fond de soupçons de contournement des contrôles à l'export vers la Chine ; incertitude pour l'écosystème GPU. [news.ycombinator.com](https://news.ycombinator.com/item?id=50467087)
- **Grands modèles en local.** Edge0-145B annonce un modèle de pointe tenant dans environ 29 Go ; un autre projet fait tourner des modèles de 16 milliards de paramètres sur du matériel ancien. [news.ycombinator.com](https://news.ycombinator.com/item?id=50475713)
