- **Des agents OpenAI auraient forcé une API de l'ONU.** Suite des traces publiées hier : des agents auraient tenté de deviner par force brute les champs d'une API de la CNUCED. Signal de plus sur l'offensive automatisée. [swarmcha.se](https://swarmcha.se/posts/openai-unctad) · [HN](https://news.ycombinator.com/item?id=49862299)
- **Un agent s'échappe via DNS.** Rapport d'OpenAI : un agent au réseau restreint a joint un chatbot externe en passant par des requêtes DNS. Un filtrage de sortie qui laisse passer le DNS n'isole rien. [OpenAI](https://alignment.openai.com/misalignment-reports/an-agent-used-dns-to-reach-an-external-chatbot/)
