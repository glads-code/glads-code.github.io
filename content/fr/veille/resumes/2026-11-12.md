**L'essentiel :** Faille critique d'exécution de code dans Apache HTTP Server via HTTP/2 et dix nouveaux errata OpenBSD 8.0 (root local, résolveur DNS, crash TCP à distance) : mises à jour à appliquer en priorité.

- **Apache httpd : RCE critique (CVE-2026-119618).** Course critique dans HTTP/2 menant à une corruption du tas ; pas d'exploitation connue, désactiver `h2` en attendant le correctif. [news.ycombinator.com](https://news.ycombinator.com/item?id=50462177)
- **OpenBSD 8.0 : errata 010 à 019.** Serveur X, zlib, root local via `kbind(2)`, débordement dans le résolveur DNS de la libc, plantages TCP à distance (SACK, syn cache). `syspatch` sans tarder. [openbsd.org](https://www.openbsd.org/errata80.html)
- **LibreSSL 4.3.5 et 4.4.1.** Versions correctives, bientôt sur les miroirs OpenBSD. [undeadly.org](https://undeadly.org/)
- **Verrouiller ses GitHub Actions.** Plaidoyer pour les fichiers de verrouillage des workflows ; le mainteneur de zizmor rappelle que les workflows réutilisables restent à épingler par hash. [news.ycombinator.com](https://news.ycombinator.com/item?id=50459485)
- **AWS Emulator.** Émulateur officiel des API AWS, écrit par des agents à partir des specs Smithy ; inutilisable pour tester IAM et les contrôles de sécurité. [news.ycombinator.com](https://news.ycombinator.com/item?id=50456631)
- **Defender envoie des binaires non publiés.** L'envoi automatique d'échantillons a téléversé un logiciel inédit sans demande explicite : à couper sur les postes Windows sensibles. [news.ycombinator.com](https://news.ycombinator.com/item?id=50461786)
- **Décès de Tim Peters.** Auteur du Zen of Python et de Timsort. [discuss.python.org](https://discuss.python.org/t/in-memoriam-tim-peters-1952-2026/110028)
