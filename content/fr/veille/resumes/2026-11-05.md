**L'essentiel :** l'IA industrialise la chasse aux failles (948 élévations de privilèges Linux corrigées d'un coup, RCE dans PHP) : un compte local sur un système non à jour vaut désormais root, d'où l'urgence des mises à jour.

- **948 chemins vers root en moins dans Linux.** OpenAI a fait trouver, valider et corriger par un pipeline autonome 948 élévations de privilèges locales du noyau ; conclusion : sans les derniers correctifs, accès local ≈ root. [news.ycombinator.com](https://news.ycombinator.com/item?id=50372929)
- **PHP2Shell : 40 ans de dette technique à rembourser.** Un bug mémoire de PHP transformé en exécution de code à distance par un audit assisté par IA ; la vague de failles touche aussi Brotli. [spectrum.ieee.org](https://spectrum.ieee.org/ai-in-cybersecurity-php2shell-vulnerability)
- **OpenBSD 8.0 : quatre errata.** Plantage d'isakmpd par IKEv1 non authentifié, failles des bibliothèques clientes X.Org, panique pf avec FQ-CoDel, blocage lié à unveil(2). [openbsd.org](https://www.openbsd.org/errata80.html)
- **Proxys résidentiels sur le réseau de la Maison-Blanche.** Un appareil y embarque un SDK de proxy monétisé : ces SDK cachés dans des applis transforment n'importe quel réseau en point de sortie. [news.ycombinator.com](https://news.ycombinator.com/item?id=50371246)
- **Go : encoding/json/v2.** Nouvelle API JSON plus stricte et rapide, avec `jsontext` pour le bas niveau ; migration à prévoir (`MarshalIndent` disparaît). [go.dev](https://go.dev/blog/jsonv2)
- **Gemini entraîné sur l'historique, même payant.** Les comptes personnels abonnés sont concernés ; vérifier les réglages de confidentialité. [news.ycombinator.com](https://news.ycombinator.com/item?id=50363461)
