**L'essentiel :** Bitwarden passe à une double licence, Microsoft publie Mxc pour confiner les agents IA, et DuckDB 2.0 détaille ses gains de performance.

- **Bitwarden : double licence.** Le code reste consultable et l'auto-hébergement personnel possible, mais l'usage commercial est davantage encadré ; la communauté s'inquiète d'une dérive. Rappel de l'intérêt d'outils simples et libres comme pass. [community.bitwarden.com](https://community.bitwarden.com/t/published-version-update-in-app-stores/102750)
- **Mxc 1.0 (Microsoft Execution Containers).** Confinement par politiques des agents IA sous Windows, avec un backend bubblewrap ; les premiers retours jugent la conception fragile. Sous Linux, bubblewrap et les conteneurs restent la référence. [blogs.windows.com](https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/)
- **DuckDB 2.0 plus rapide.** Explication des optimisations (CTE récursives notamment) et nouvelle API d'extensions C++. [motherduck.com](https://motherduck.com/blog/why-duckdb-20-is-faster/)
- **Unikernels, le retour ?** Selon l'auteur, les agents IA rendent leur construction accessible ; la discussion rappelle le coût en observabilité sans OS complet. [ghuntley.com](https://ghuntley.com/unikernels/)
- **Nix comme moteur d'un débogueur.** Les dérivations Nix servent de cache reproductible pour un débogueur à la rr. [fzakaria.com](https://fzakaria.com/2026/10/07/nix-wrote-half-of-my-debugger)
- **Rampart : anonymisation dans le navigateur.** Masquage des données personnelles avant envoi à un chatbot, entièrement local ; piste intéressante côté RGPD, mais non déterministe. [ndstudio.gov](https://ndstudio.gov/posts/say-hello-to-rampart)
